# Banking Management System in C++

## Description

The Banking Management System is a menu-driven C++ application that simulates basic banking operations. It allows users to create accounts, deposit and withdraw money, check balances, display account details, transfer money, and calculate interest.

The project is developed using C++ Object-Oriented Programming concepts and is structured into multiple files for better code organization and maintainability.

## Features

* Create Savings and Current accounts
* Deposit money
* Withdraw money
* Check account balance
* Display all accounts
* Transfer money between accounts
* Calculate interest for Savings accounts
* Exception handling for invalid transactions

## C++ Concepts Used

* Classes and Objects
* Encapsulation
* Abstraction
* Constructors and Destructor
* Constructor Overloading
* Copy Constructor
* Inheritance
* Function Overriding
* Virtual Functions
* Abstract Class
* Operator Overloading
* Templates
* Namespace
* Exception Handling
* Dynamic Memory Allocation using `new` and `delete`
* STL `vector`
* STL `string`
